# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep discussion about the work.
Harassment, personal attacks and discriminatory language aren't welcome in
issues, pull requests, discussions or anywhere else this project lives.

## Reporting

If someone's behaviour is a problem, contact the maintainers privately. The
simplest way is a private security advisory (**Security → Report a
vulnerability**) with "Code of conduct" in the title; it's only visible to
the maintainers. Reports are kept confidential.

Maintainers may edit or remove comments, commits and issues that break
these rules, and may block people who keep breaking them, following the
enforcement guidelines in the Contributor Covenant linked above.
